# Simulador — Java Web (Capacita Brasil / iRede)

Material interativo do módulo de JPA/Hibernate, REST com Spring Boot, segurança e documentação de APIs.

🌐 **Acesse:** https://irede-java-c2.github.io/simulador/
🛠️ **Projeto da turma:** https://github.com/irede-java-c2/taskmanager-api

O sumário segue o calendário: são 9 assuntos e 18 aulas, e cada assunto é liberado no dia da sua primeira aula. O código de cada aula fica na tag `aula-NN` do repositório do projeto.
