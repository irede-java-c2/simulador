Reproduza, passo a passo, o que as aulas 11 e 12 entregam no taskmanager-api: o ModelMapper como bean, o UsuarioService e o TarefaService com o CRUD completo (aula 11), o PATCH, o 201 com Location absoluto, a paginação e o sub-recurso /usuarios/{id}/tarefas (aula 12), fechando a release v0.2.0. Tente resolver por conta própria e depois revele a solução para conferir.

ModelMapper no pom.xml e o AppConfig
Básico
Aula 11: prepare o projeto para o mapeamento automático. Adicione a biblioteca e faça o passo "Obrigatório!" do slide: ensinar o Spring a criar e gerenciar o ModelMapper.
Requisitos
  • Dependência org.modelmapper:modelmapper no pom.xml, com <version> explícita (o Spring Boot não gerencia essa versão)
  • Classe AppConfig no pacote config, com @Configuration
  • Método @Bean modelMapper() que retorna new ModelMapper()
  • No NetBeans: Clean and Build (Shift+F11) para baixar a dependência e subir a aplicação
Solução
<!-- pom.xml, dentro de <dependencies> --> <dependency> <groupId>org.modelmapper</groupId> <artifactId>modelmapper</artifactId> <version>3.2.0</version> </dependency>
package br.org.irede.taskmanagerapi.config; import org.modelmapper.ModelMapper; import org.springframework.context.annotation.Bean; import org.springframework.context.annotation.Configuration; @Configuration public class AppConfig { @Bean public ModelMapper modelMapper() { return new ModelMapper(); } }

2)
UsuarioService e um UsuarioController enxuto
Básico
Reproduza o slide "Usando o ModelMapper (é simples!)" com o Usuario: crie a camada de serviço do usuário e tire do UsuarioController o repositório e o converterParaDto manual da aula 10.
Requisitos
  • Pacote novo service com a classe UsuarioService anotada com @Service
  • UsuarioRepository e ModelMapper injetados pelo construtor
  • buscarPorId(Long) devolvendo UsuarioDTO com modelMapper.map(...)
  • buscarUsuario(Long) público, devolvendo a entidade ou lançando ResourceNotFoundException (será usado pelo TarefaService)
  • UsuarioController recebendo só o UsuarioService
Solução
package br.org.irede.taskmanagerapi.service; import br.org.irede.taskmanagerapi.dto.UsuarioDTO; import br.org.irede.taskmanagerapi.exception.ResourceNotFoundException; import br.org.irede.taskmanagerapi.model.Usuario; import br.org.irede.taskmanagerapi.repository.UsuarioRepository; import org.modelmapper.ModelMapper; import org.springframework.stereotype.Service; @Service public class UsuarioService { private final UsuarioRepository repository; private final ModelMapper modelMapper; public UsuarioService(UsuarioRepository repository, ModelMapper modelMapper) { this.repository = repository; this.modelMapper = modelMapper; // Injeta o bean do AppConfig } public UsuarioDTO buscarPorId(Long id) { // Mapeamento automático! return modelMapper.map(buscarUsuario(id), UsuarioDTO.class); } public Usuario buscarUsuario(Long id) { return repository.findById(id) .orElseThrow(() -> new ResourceNotFoundException("Usuário com id " + id + " não encontrado")); } }
package br.org.irede.taskmanagerapi.controller; import br.org.irede.taskmanagerapi.dto.UsuarioDTO; import br.org.irede.taskmanagerapi.service.UsuarioService; import org.springframework.web.bind.annotation.*; @RestController @RequestMapping("/api/v1/usuarios") public class UsuarioController { private final UsuarioService service; public UsuarioController(UsuarioService service) { this.service = service; } @GetMapping("/{id}") public UsuarioDTO buscarPorId(@PathVariable Long id) { return service.buscarPorId(id); } }

TarefaService: o CRUD Completo com DTOs e Serviços
Intermediário
Feche a aula 11: a conversão vai para a Camada de Serviço, e "o Controlador e o Cliente Externo nunca tocam na Entidade". Mova tudo o que o TarefaController da aula 10 fazia além de HTTP para um TarefaService. A coleção do Postman tem que passar inteira, sem alteração.
Requisitos
  • TarefaService com listar, buscarPorId, criar, atualizar e remover, todos trabalhando com TarefaDTO
  • O dono buscado pelo UsuarioService.buscarUsuario (não pelo UsuarioRepository)
  • Saída com modelMapper.map(tarefa, TarefaDTO.class); entrada com copiarParaEntidade campo a campo (o id e o dono nunca vêm do cliente)
  • TarefaController recebendo só o TarefaService, sem nenhum import de model ou repository
Solução
package br.org.irede.taskmanagerapi.service; // imports: TarefaDTO, ResourceNotFoundException, Tarefa, Usuario, TarefaRepository, // java.util.List, org.modelmapper.ModelMapper, org.springframework.stereotype.Service @Service public class TarefaService { private final TarefaRepository repository; private final UsuarioService usuarioService; private final ModelMapper modelMapper; public TarefaService(TarefaRepository repository, UsuarioService usuarioService, ModelMapper modelMapper) { this.repository = repository; this.usuarioService = usuarioService; this.modelMapper = modelMapper; } public List<TarefaDTO> listar() { return repository.findAll().stream() .map(this::converterParaDto) .toList(); } public TarefaDTO buscarPorId(Long id) { return converterParaDto(buscarTarefa(id)); } public TarefaDTO criar(TarefaDTO dto) { Usuario dono = usuarioService.buscarUsuario(dto.getUsuarioId()); Tarefa tarefa = new Tarefa(); copiarParaEntidade(dto, tarefa); tarefa.setUsuario(dono); return converterParaDto(repository.save(tarefa)); } public TarefaDTO atualizar(Long id, TarefaDTO dto) { Tarefa tarefa = buscarTarefa(id); copiarParaEntidade(dto, tarefa); // o dono não muda no PUT return converterParaDto(repository.save(tarefa)); } public void remover(Long id) { if (!repository.existsById(id)) { throw new ResourceNotFoundException("Tarefa com id " + id + " não encontrada"); } repository.deleteById(id); } private Tarefa buscarTarefa(Long id) { return repository.findById(id) .orElseThrow(() -> new ResourceNotFoundException("Tarefa com id " + id + " não encontrada")); } private TarefaDTO converterParaDto(Tarefa tarefa) { return modelMapper.map(tarefa, TarefaDTO.class); } private void copiarParaEntidade(TarefaDTO dto, Tarefa tarefa) { tarefa.setTitulo(dto.getTitulo()); tarefa.setDescricao(dto.getDescricao()); tarefa.setPrioridade(dto.getPrioridade()); tarefa.setPrazo(dto.getPrazo()); tarefa.setConcluida(dto.isConcluida()); } }
package br.org.irede.taskmanagerapi.controller; // imports: TarefaDTO, TarefaService, jakarta.validation.Valid, java.net.URI, java.util.List, // org.springframework.http.ResponseEntity e org.springframework.web.bind.annotation.* @RestController @RequestMapping("/api/v1/tarefas") public class TarefaController { private final TarefaService service; public TarefaController(TarefaService service) { this.service = service; } @GetMapping public List<TarefaDTO> listar() { return service.listar(); } @GetMapping("/{id}") public TarefaDTO buscarPorId(@PathVariable Long id) { return service.buscarPorId(id); } @PostMapping public ResponseEntity<TarefaDTO> criar(@Valid @RequestBody TarefaDTO dto) { TarefaDTO criada = service.criar(dto); URI location = URI.create("/api/v1/tarefas/" + criada.getId()); return ResponseEntity.created(location).body(criada); } @PutMapping("/{id}") public TarefaDTO atualizar(@PathVariable Long id, @Valid @RequestBody TarefaDTO dto) { return service.atualizar(id, dto); } @DeleteMapping("/{id}") public ResponseEntity<Void> remover(@PathVariable Long id) { service.remover(id); return ResponseEntity.noContent().build(); } }

PATCH e 201 com Location Absoluto
Intermediário
Aula 12, "PUT vs. PATCH": o PUT substitui a tarefa inteira, mas o cliente quer só marcar como concluída sem reenviar tudo. Crie a atualização parcial e, de quebra, faça o Location do POST apontar para o endereço completo do recurso criado.
Requisitos
  • TarefaDTO.concluida passa de boolean para Boolean (getter getConcluida())
  • No copiarParaEntidade do PUT: Boolean.TRUE.equals(dto.getConcluida()), para que ausente continue valendo false
  • TarefaService.atualizarParcial(Long, TarefaDTO) copiando só os campos não nulos
  • @PatchMapping("/{id}") no controller, sem @Valid
  • Location montado com ServletUriComponentsBuilder.fromCurrentRequest()
  • Requisições "Concluir tarefa (PATCH)" e "Concluir tarefa inexistente" na coleção
Solução
// TarefaDTO.java private Boolean concluida; public Boolean getConcluida() { return concluida; } public void setConcluida(Boolean concluida) { this.concluida = concluida; }
// TarefaService.java public TarefaDTO atualizarParcial(Long id, TarefaDTO dto) { Tarefa tarefa = buscarTarefa(id); // 404 de graça if (dto.getTitulo() != null) tarefa.setTitulo(dto.getTitulo()); if (dto.getDescricao() != null) tarefa.setDescricao(dto.getDescricao()); if (dto.getPrioridade() != null) tarefa.setPrioridade(dto.getPrioridade()); if (dto.getPrazo() != null) tarefa.setPrazo(dto.getPrazo()); if (dto.getConcluida() != null) tarefa.setConcluida(dto.getConcluida()); return converterParaDto(repository.save(tarefa)); } private void copiarParaEntidade(TarefaDTO dto, Tarefa tarefa) { // ... título, descrição, prioridade e prazo como antes tarefa.setConcluida(Boolean.TRUE.equals(dto.getConcluida())); // null → false }
// TarefaController.java (import org.springframework.web.servlet.support.ServletUriComponentsBuilder) @PostMapping public ResponseEntity<TarefaDTO> criar(@Valid @RequestBody TarefaDTO dto) { TarefaDTO criada = service.criar(dto); URI location = ServletUriComponentsBuilder.fromCurrentRequest() .path("/{id}") .buildAndExpand(criada.getId()) .toUri(); return ResponseEntity.created(location).body(criada); } @PatchMapping("/{id}") public TarefaDTO atualizarParcial(@PathVariable Long id, @RequestBody TarefaDTO dto) { return service.atualizarParcial(id, dto); }

💡 Por que sem @Valid no PATCH? Porque o TarefaDTO exige prioridade e usuarioId: com @Valid, o {"concluida": true} daria 400. O preço é que um {"titulo": ""} passaria sem validação; uma saída é um DTO próprio para o PATCH, ou grupos de validação, que ficam fora do escopo desta aula. No Postman, o Location absoluto vira link clicável: abre um GET para a tarefa 9.

Paginação, Sub-recurso e a Coleção da v0.2.0
Avançado
Feche a aula 12 e o Marco 2 · API REST. A coleção de tarefas não pode voltar inteira de uma vez, e as tarefas de um usuário devem ser acessíveis pela hierarquia (Convenção 2). Reaproveite o que a Fase 1 já construiu: o buscarComFiltros(TarefaFiltro, Pageable) da aula 06 e o findByUsuarioId da aula 05.
Requisitos
  • GET /tarefas devolvendo Page<TarefaDTO>, aceitando ?prioridade=&usuarioId=&page=&size=&sort=, com padrão de 10 por página ordenadas por id
  • spring.data.web.pageable.serialization-mode=via-dto no application.properties
  • GET /usuarios/{id}/tarefas no UsuarioController, com 404 para usuário inexistente
  • Coleção do Postman atualizada e exportada (Collection v2.1); <version>0.2.0</version> no pom.xml
Solução
// TarefaService.java (imports: TarefaFiltro, Page, Pageable) public Page<TarefaDTO> listar(TarefaFiltro filtro, Pageable pageable) { return repository.buscarComFiltros(filtro, pageable).map(this::converterParaDto); } public List<TarefaDTO> listarPorUsuario(Long usuarioId) { usuarioService.buscarUsuario(usuarioId); // o pai precisa existir return repository.findByUsuarioId(usuarioId).stream() .map(this::converterParaDto) .toList(); }
// TarefaController.java (imports: TarefaFiltro, Page, Pageable, org.springframework.data.web.PageableDefault) @GetMapping public Page<TarefaDTO> listar(TarefaFiltro filtro, @PageableDefault(size = 10, sort = "id") Pageable pageable) { return service.listar(filtro, pageable); } // UsuarioController.java — agora com os dois services private final UsuarioService service; private final TarefaService tarefaService; public UsuarioController(UsuarioService service, TarefaService tarefaService) { this.service = service; this.tarefaService = tarefaService; } @GetMapping("/{id}/tarefas") public List<TarefaDTO> listarTarefas(@PathVariable Long id) { return tarefaService.listarPorUsuario(id); }

💡 O TarefaFiltro não tem anotação no parâmetro: o Spring trata um objeto simples como @ModelAttribute e preenche os campos com os parâmetros de mesmo nome (?prioridade=ALTA → setPrioridade). Na página 0, o Hibernate omite o offset; na página 1, aparece offset ? rows. Repare na ordem por prazo: a tarefa 8 (ALTA, sem prazo) fica por último, porque no PostgreSQL o NULL vem depois na ordem crescente.
